ANUPBistro - HTML/CSS/JavaScript Mobile App

FILES
- index.html : main app page
- style.css  : responsive mobile design
- app.js     : all customer/admin logic and localStorage data
- assets/    : local SVG food/restaurant images

RUN IN BROWSER
1. Keep the folder structure unchanged.
2. Open index.html in Chrome/Edge.
3. Choose Customer or Admin.

CUSTOMER FLOW
Login -> Restaurant List -> Menu -> Bill -> Order Confirmation

ADMIN FLOW
Login -> Admin Dashboard -> Add Restaurant / Daily Transactions / Bill Details

DATA
Orders and added restaurants are saved in browser localStorage.
No server/database is required for this demo.

ANDROID
Use the separate ANUPBistro_AndroidProject_FIXED folder to open in Android Studio.
